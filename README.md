# Power BI Sales Performance Dashboard
 
## Project Overview
Interactive Power BI dashboard analyzing retail sales across 3 regions 
and 5 product categories. This project demonstrates data visualization, 
trend analysis, and KPI tracking.
 
## Key Metrics
- **Total Revenue**: ₹5.2 Million
- **Units Sold**: 12,500+
- **Average Order Value**: ₹416
- **Top Region**: North (45% of total revenue)
 
## Dashboard Features
✓ Monthly revenue trends with YoY comparison
✓ Regional sales breakdown (North, South, East)
✓ Product category performance analysis
✓ Interactive filters (Date range, Category, Region)
✓ Key performance indicators (KPIs)
 
## Data Source
- Dataset: Retail_Sales_2024.csv
- Size: 5,000+ transactions
- Date Range: January - December 2024

## How to Use
1. Download "dashboard.pbix" file
2. Open in Power BI Desktop (free download)
3. Click filters to explore data
4. Hover over charts for details
 
## Key Findings
1. Electronics category: 35% of revenue (top performer)
2. Fashion category: Trending up 12% YoY (growth opportunity)
3. North region: Outperforms other regions significantly
4. Strong Q4 spike: Holiday season impact
